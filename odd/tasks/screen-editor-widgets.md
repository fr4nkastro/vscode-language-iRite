- L3 (evidence, T1): REA `rea-agents` 6.10.1 under node@26 in scratch (`inspect-managed-members ... --max-metadata-representation-bytes 1500000000 --json`) gave types/members/call edges/ldstr; method bodies read with ILSpy 8.2 (scratch only, never in repo). 11 widget types (1 Scale, 2 Bitmap, 3 Bargraph, 4 Label, 5 Numeric legacy, 6 Symbol, 7 Image, 8 Chart, 9 Softkey, 10 Line, 11 Monospace label); catalog checked against 21,462 WDGT lines of ~60 real `.rev` files, 0 mismatches. Findings: `/home/frank/.cache/gentle-tasks/rea-screen-editor/FINDINGS.md`, `catalog.json`; clean-room draft `docs/rev-format.md`.
- L4 (evidence, hash): ConfigHash = SHA-1 over UTF-16LE (no BOM) of the XML-decoded `<Config>` text with CRLF, each digest byte written as decimal + one space; CustomHash same function over `<Printers>`. Reproduced on all samples; DOLE's current `main.rev` hash is stale because of a later hand patch (DOLE commit `a495703`), its blob at `00fe873` matches (`reproduce_confighash.py --crlf`). Supersedes issue #6 L3.
- L5 (decision, hash on save): S2c applies — recompute ConfigHash on every save that changes `Config` text; open+save without edits stays byte-identical. The `ConfigHash` header line is the only non-WDGT line allowed to change.
- L6 (evidence/decision, escaping): Config text XML-escapes only `&`, `<`, `>`; a WDGT value is a plain comma split/join with no escaping, max 255 chars; Revolution strips commas and cuts captions to 64 chars, aliases cut to 8 chars. Decision: serializer refuses any token containing a comma, CR/LF, or a value over 255 chars; editor validates captions (≤64, no comma) and aliases (iRite identifier, ≤8 chars, unique; DOLE's longest alias is 8).
- L7 (evidence/decision, ids): Revolution's new id = lowest free id starting at 1 (ids 1–999); default alias = type prefix + id (`lbl`, `mlbl`, `bar`, `sym`, `img`, `bit`, `cht`, `line`, `sk`); Scale has no alias; Line and Softkey aliases are not stored in `.rev`. `main.iri` block: `-- Widget Aliases`, alias padded to 10 then `: constant integer := <id>;`, CRLF, ascending id. The editor follows these rules.
- L8 (evidence/decision, paint order): Revolution's designer paints by ascending id with scale widgets last; loader re-sorts by id; no z-order field exists. Z-order stays view-only (S12). Designer client area is 800x384 (7") / 1280x704 (12") under a 42 px title bar, contradicting the preview's 92/147.2 px header assumption — recorded as a follow-up, not changed in this feature.
